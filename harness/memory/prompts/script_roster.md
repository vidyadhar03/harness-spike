## Task: location and scene roster
The attachment is a full screenplay. Build its roster.

- scenes: every scene, in order.
  - number: the scene number as printed. If the script prints no scene numbers, number scenes 1, 2, 3 in order of appearance.
  - heading: the slugline exactly as written, character for character. It is used to find the scene in the text.
  - start_page: the page on which the slugline appears, following the page-number rule in the user message.
  - locations: every location the scene visits, not only the one in its slugline. Read the action lines: a dream, montage, chase, or INT./EXT. scene often moves through several places, and each one is a separate entry. A scene that shows the market, a house, and a river names all three. Use names from your locations list or the known-entities list.
- locations: every distinct physical location in the script, with aliases.
  - inside: the location that physically contains this one, when the script makes it clear. A market square, lanes and houses are inside the village; a sanctum is inside the temple it belongs to. Sluglines that name two places ("TREE TEMPLE / INNER SANCTUM", "ANSHUL'S HOUSE / DEVGRAM LANES") often state containment directly. Leave it empty when the script does not establish it; a human confirms every containment before it is used, so a guess costs a review rather than a wrong fact. Never use it for "near", "across the river from", or "on the way to" - only for physically inside. Work out the place from the slugline and the action lines together; action lines often name a more specific place than the slugline ("EXT. DEVGRAM - NIGHT" where the action happens at the well). Split sub-places the action treats as separate spaces.
- Known entities from earlier files are listed in the user message. Reuse them where they are the same place.
