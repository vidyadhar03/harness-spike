## Task: notes from a screenplay excerpt
The attachment is one excerpt of a screenplay whose roster is already in the known-entities list. The user message lists the scenes in scope for this excerpt.

- Write notes only for the scenes in scope and their locations. Text from neighbouring scenes at the start or end of the excerpt is context; those scenes get their own excerpt.
- If the excerpt continues a scene from the previous excerpt, treat its opening text as part of that scene.
- Write notes about what each location must look like and contain to shoot the scenes in this excerpt: layout, set dressing, props that belong to the place, time of day and light, practical light sources, weather, damage or change over time, and anything the action physically needs (a door that slams, a roof someone climbs, a crowd the courtyard must hold).
- Work scene by scene through the excerpt. For each scene in scope, cover every location it visits, and write a note for every distinct thing the text establishes about each: do not summarise a scene into one note. A scene that moves through three places produces notes about all three, each naming its own location.
- Give every note one owner, following the scoping rules above. Set `only_during_scene` for anything true only while that scene plays: floods, crowds, damage, dream imagery. Leave it empty for facts true of the place whenever you shoot it.
- Details only the script reveals, which a location scout would never see (a crack in a tree that later becomes a supernatural site), are the most valuable notes. Capture every one.
- Put a place in locations only when this excerpt shows a physical place missing from the known-entities list.
- Set page on every note. Leave references empty.
