## Task: notes from a visual document excerpt
The attachment is an excerpt of a visual document: a lookbook, mood board, treatment, or recce deck.

- references: one entry per page whose imagery can serve as a reference for a place.
  - caption: 1 to 3 sentences describing what is visible in concrete visual terms: what the place is, layout, materials, condition, light, time of day, and scale cues.
  - locations: the location(s) the page references. Use known names when the page title, captions, or content make the match clear. Otherwise propose the most specific place name the page supports, or leave the list empty when the page gives no basis.
  - page: the page's position within this excerpt, as described in the user message.
- notes: facts stated or clearly shown on the pages (palette, period, materials, lighting style, things that must not appear) as description, constraint, or tone notes, with page set the same way.
- Title cards, credits, and text-free decoration get no entries.
