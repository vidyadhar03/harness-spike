## Task: notes from a production document
The attachment is production text: research, recce notes, director's notes, a schedule, or similar.

- Capture location descriptions, constraints, and tone as notes.
- From schedules and logistics, keep only facts that change how a location looks or can be shot ("the house is occupied during the day, shoot after sunset", "market stalls are only set up on Sundays").
- Real-world places named as candidates for a story location (a village, a temple, an address) go in a description note on the story location, including the real name and any address or region given.
- Put a place in locations only when the document describes a physical place missing from the known-entities list.
- Leave references empty.
